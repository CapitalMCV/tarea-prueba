# AGENTS.md - Taller Mecánico Don Ramiro

Página web sencilla para consultar el estado de vehículos y aprobar o rechazar cotizaciones de reparaciones adicionales.
(Es un mini proyecto académico)

## STACK y Estructura
- Utilizar HTML, CSS y JavaScript: sin framework, librerías o dependencias.
- `index.html` (estructura), `styles.css` (estilos), `app.js` (lógica y datos).

## Instrucciones
- Leer constitution.md antes de desarrollar.
- Revisar la especificación correspondiente en specs/.
- Utilizar las skills de skills/ cuando correspondan.
- Mantener la interfaz en español y adaptable a celulares.
- No agregar funcionalidades fuera de las especificaciones.
- Verificar los criterios de aceptación antes de finalizar.

## Memoria
- Al comenzar, leer MEMORY.md para conocer el estado del proyecto.
- Al terminar, actualizar MEMORY.md con avances, decisiones y problemas pendientes.
